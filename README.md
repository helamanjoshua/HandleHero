# Handle Hero – Hands-Free Door Opener

## Project Overview
Handle Hero is a device designed to help people open doors while carrying groceries or other items. The system actuates the door latch, allowing the user to push the door open without manually operating the handle.

## Design and Engineering
- Designed a mechanical latch-actuation system.
- Developed a custom strike plate and housing.
- Integrated a servo motor and control system.
- Designed the device to minimize modifications to the existing door.
